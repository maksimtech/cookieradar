# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2026.09.x | ✅ |

## Reporting Vulnerabilities

Please report security issues to **security@maksimtech.com**  
GPG public key: https://keys.openpgp.org/search?q=security@maksimtech.com

Do not open public GitHub issues for security vulnerabilities.

## Known Open CVEs

All currently open CVEs affect Debian Bookworm system packages (OpenSSL, Perl, util-linux, zlib).
These are unrelated to CookieRadar's Python codebase and are pending Debian security backports.
They will be automatically patched on the next Docker build after Debian releases the fixes.
